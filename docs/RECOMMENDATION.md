# 추천 기준

추천 알고리즘은 반드시 만족해야 하는 하드 제약 조건으로 후보를 걸러낸 뒤, 소프트 제약
조건을 점수화해 더 적합한 시간표를 우선 제시합니다.

## 하드 제약 조건

- 같은 시간에 겹치는 수업을 함께 선택할 수 없다.
- 한 과목에서는 하나의 분반만 선택한다.
- 사용자가 이미 이수한 과목은 제외한다.
- 사용자가 입력한 목표 과목 수를 만족해야 한다.
- `INCOMPATIBLE` 관계인 두 과목을 같은 시간표에 포함하지 않는다.
- MAS109를 이수했을 경우 MAS110을 추천하지 않는다. 마찬가지로 MAS110을 이수했을 경우 MAS109를 추천하지 않는다.
- CS206을 이수했을 경우, CS109를 추천하지 않는다.

마지막 두 규칙은 CSV에 `INCOMPATIBLE` 관계로 저장되며 추천 엔진은 관계를 양방향으로
해석합니다.
## 소프트 제약 조건

- 사용자가 선택한 관심 분야와 일치하는 과목을 우선한다.
- 전공필수 과목을 우선한다.
- 사용자가 선택한 미관심 분야의 과목은 우선 순위에서 밀려난다.
- 학년과 과목 번호에 따라 다음 가산점을 부여한다.
  - 1학년: 100번대 +35점, 200번대 +20점
  - 2학년: 200번대 +35점, 300번대 +20점
  - 3학년: 200번대 +30점, 300번대 +35점, 400번대 +25점
  - 4학년 이상: 300번대 +20점, 400번대 +20점, 전공필수 및 CS101 +30점
- 선수과목 관계별 점수
  - `RECOMMENDED`: 이수 +0점, 미이수 -1점
  - `PREREQUISITE`: 이수 +0점, 미이수 -3점

## 점수 계산 공식

시간표의 최종 점수는 시간표에 포함된 각 과목의 점수를 모두 더해 계산합니다.

```text
최종 점수 = Σ(과목 점수)

과목 점수 = 관심 분야 점수
          + 미관심 분야 점수
          + 전공필수 점수
          + 학년·과목 번호 점수
          + Σ(RECOMMENDED 선수과목 점수)
          + Σ(PREREQUISITE 선수과목 점수)
```

### 과목별 점수

| 항목 | 조건 | 점수 |
|---|---|---:|
| 관심 분야 | 과목의 관심 분야가 사용자의 관심 분야와 하나 이상 일치 | +1 |
| 미관심 분야 | 과목의 관심 분야가 사용자의 미관심 분야와 하나 이상 일치 | -1 |
| 전공필수 | 과목 유형이 전공필수 | +10 |

학년·과목 번호 점수는 과목 코드 끝의 세 자리 숫자로 번대를 판별하며, 위의
학년별 가산점 표에 해당하지 않는 번대는 0점입니다.

현재 API는 모든 하드 제약을 만족하는 조합 중 점수가 가장 높은 시간표 하나를 반환합니다.
동점이면 과목 코드와 분반 키를 기준으로 결정적으로 선택합니다. 가능한 조합이 없으면
`timetable`은 `null`입니다. 상위 시간표를 최대 5개 반환하는 기능은 후속 범위입니다.
