# 추천 기준

추천 알고리즘은 반드시 만족해야 하는 하드 제약 조건으로 후보를 걸러낸 뒤, 소프트 제약
조건을 점수화해 더 적합한 시간표를 우선 제시합니다.

## 하드 제약 조건

- 같은 시간에 겹치는 수업을 함께 선택할 수 없다.
- 한 과목에서는 하나의 분반만 선택한다.
- 사용자가 이미 이수한 과목은 제외한다.
- 공식 선수 과목(`PREREQUISITE`)을 충족해야 한다.
- 사용자가 입력한 목표 과목 수를 만족해야 한다.

## 소프트 제약 조건

- 사용자가 선택한 관심 분야와 일치하는 과목을 우선한다.
- 전공필수 과목을 우선한다.
- 수업 사이의 공강을 최소화한다.
- 사용자가 선택한 미관심 분야의 과목은 우선 순위에서 밀려난다.

최종적으로 시간 충돌이 없는 시간표를 최대 5개 추천하는 것이 MVP 목표입니다.
