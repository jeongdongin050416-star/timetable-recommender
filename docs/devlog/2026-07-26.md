## 오늘의 목표

프로젝트의 기본 구조와 데이터베이스 스키마를 만든다.

## 구현한 내용

### 프론트엔드

React, TypeScript, Vite로 프론트엔드를 구성했다.

```bash
cd frontend
npm install
npm run dev
```

- `npm install`: `package.json`을 읽고 React, Vite 등의 라이브러리를
  `node_modules`에 설치한다.
- `npm run dev`: `package.json`의 `dev` 스크립트에서 Vite를 찾아 프론트엔드 개발
  서버를 시작한다.

### 백엔드

Java 21, Spring Boot, Gradle로 백엔드를 구성했다. 현재 API는 서버의 상태를 확인하는
`GET /api/health` 하나이며, 백엔드는 `http://localhost:8080`에서 실행된다.

```bash
cd backend
./gradlew bootRun
```

Gradle은 Java 프로젝트를 빌드·실행하고 필요한 라이브러리를 관리한다. Node.js
프로젝트에서 npm이 담당하는 역할과 비슷하다.

### PostgreSQL

Docker Compose 설정을 `docker-compose.yml`에 작성해 명령 하나로 PostgreSQL을 실행할
수 있게 했다.

```bash
# 백그라운드 실행
docker compose up -d

# 컨테이너 종료
docker compose down

# 컨테이너와 DB 데이터 볼륨 삭제
docker compose down -v
```

`ports`의 `"5432:5432"`는 호스트의 5432 포트로 들어온 연결을 PostgreSQL 컨테이너의
5432 포트로 전달한다. 따라서 호스트에서 직접 실행하는 백엔드는
`localhost:5432`로 DB에 접속할 수 있다.

`application.yml`의 기본 접속 설정은 다음과 같다.

```yaml
datasource:
  url: ${DB_URL:jdbc:postgresql://localhost:5432/timetable}
  username: ${DB_USERNAME:timetable}
  password: ${DB_PASSWORD:timetable}
```

환경 변수를 지정하지 않았을 때의 접속 정보:

- 주소: `localhost`
- 포트: `5432`
- 데이터베이스: `timetable`
- 사용자: `timetable`
- 비밀번호: `timetable`

접속 흐름:

```text
Spring Boot가 application.yml 확인
                 ↓
jdbc:postgresql://localhost:5432/timetable 접속
                 ↓
Docker가 호스트의 localhost:5432 요청 수신
                 ↓
PostgreSQL 컨테이너의 5432 포트로 전달
                 ↓
timetable 데이터베이스 접속
```

원격 DB가 아니라 로컬 컴퓨터의 Docker 컨테이너에서 PostgreSQL 서버를 실행하는
구조이다.

## Flyway와 JPA

- Flyway: DB 구조 변경 SQL을 버전별로 관리한다. Spring Boot가 시작되면 아직 적용되지
  않은 마이그레이션을 PostgreSQL에서 실행한다.
- JPA: Java 객체와 관계형 DB를 연결하는 표준 규칙이다. DB 테이블을 Java 코드의
  엔티티로 다룰 수 있게 한다.

## 전체 시스템 흐름

```text
사용자 브라우저
      ↓
React 프론트엔드 (localhost:5173)
      ↓ 앞으로 API 요청
Spring Boot 백엔드 (localhost:8080)
      ↓ JDBC로 데이터 조회·저장
PostgreSQL 데이터베이스 (localhost:5432)
```

현재 실행 위치를 정리하면 프론트엔드는 npm, 백엔드는 Gradle을 통해 호스트에서 직접
실행하고 PostgreSQL만 Docker 컨테이너에서 실행한다.

## 중요하게 본 파일

- `docker-compose.yml`: PostgreSQL 실행 방법
- `backend/build.gradle`: Java 버전, Spring Boot와 백엔드 라이브러리
- `backend/src/main/resources/application.yml`: 백엔드 포트와 DB 접속 정보
- `HealthController.java`: `GET /api/health` 구현
- `frontend/src/App.tsx`: 현재 화면에 표시되는 내용
