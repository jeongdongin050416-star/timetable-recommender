## 구현한 내용과 공부한 내용

- React + TypeScript + Vite로 frontend 설정
'''bash
cd frontend
npm install
npm run dev
'''
npm install: package.json을 읽고 React, Vite 등의 라이브러리를 node_modules 폴더에 설치
npm run dev: 프론트엔드 개발용 서버를 실행
package.json에서 dev 명령을 찾음 -> vite 실행 -> 개발용 웹 서버 시작
- Java 21 + Spring Boot + Grandle로 backend 설정
지금은 서버가 정상적으로 살아 있는지 확인하는 API인
GET /api/health만 있다.
다음 명령어로 백엔드를 실행한다.
'''bash
cd backend
./gradlew bootRun
'''
실행주소는 http://localhost:8080이다.

Grandle: Java 프로젝트를 빌드하고 실행하며, 필요한 라이브러리를 관리하는 도구
Node.js 프로젝트에서 npm이 하던 역할과 비슷하다.
Docker: 프로그램을 다른 프로그램과 분리된 작은 실행 환경인 컨테이너에서 실행하게 해주는 도구
Docker를 사용해서 프로젝트에 설정을 적어두고 명령어 하나로 PostgreSQL을 실행할 수 있음. 설정은 docker-compose.yml에 적혀있다.
ports: "5432:5432"라 되어 있기 때문에 내 컴퓨터의 5432포트로 연결하면 Docker 컨테이너의 5432번 포트로 연결된다. 따라서 backend는 localhost:5432로 데이터베이스에 접속할 수 있다.
실행
'''bash
docker compose up -d
'''
종료
'''bash
docker compose down
'''
데이터까지 삭제
'''bash
docker compose down -v
'''

backend/src/main/resources/application.yml(백엔드 포트와 데이터베이스 접속 정보 정의)에 
'''yml
datasource:
  url: ${DB_URL:jdbc:postgresql://localhost:5432/timetable}
  username: ${DB_USERNAME:timetable}
  password: ${DB_PASSWORD:timetable}
'''
라고 되어있다.

백엔드에서 database에 다음과 같이 접속한다.
주소: localhost
포트: 5432
데이터베이스: timetable
아이디: timetable
비밀번호: timetable

연결흐름은 다음과 같다.

Spring Boot
application.yml 확인
        ↓
jdbc:postgresql://localhost:5432/timetable 접속
        ↓
Docker가 localhost:5432 요청 수신
        ↓
PostgreSQL 컨테이너의 5432번 포트로 전달
        ↓
timetable 데이터베이스 접속

현재 설정상 백엔드가 PostgreSQL 데이터 베이스와 연결된 상태이다.
원격 DB 서버가 아니라, 내 컴퓨터의 Docker 컨테이너 안에서 PostgreSQL DB 서버를 실행하고 localhost:5432로 접속했다.
정리: 
프론트엔드: 컴퓨터에서 npm으로 직접 실행
백엔드: 컴퓨터에서 Gradle로 직접 실행
PostgreSQL: Docker 컨테이너에서 실행
